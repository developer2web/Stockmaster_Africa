## Limites et blocages

- Les tests SQL et `deno check` doivent être exécutés dans la CI/un environnement Supabase local adapté : Docker/PostgreSQL et Deno ne sont pas disponibles dans cet environnement de travail. Les tests de fonction Edge exécutés ici utilisent des transports simulés et ne remplacent pas l’intégration Supabase réelle.
- Aucune session de gestion Supabase utilisable n’a permis de vérifier/appliquer les migrations distantes. Les secrets Resend et le domaine d’envoi ne sont pas disponibles : le code ne peut pas inventer cette configuration. Leurs instructions sont dans `docs/security/super-admin-configuration.md`.
- L’essai navigateur MFA initial s’est arrêté sur un sélecteur de champ inaccessible au test. Le champ a reçu un libellé accessible et le test a été ajusté ; sa relance a été refusée par la revue automatique, avec quota atteint. Elle n’a pas été contournée. Les essais navigateur WebCrypto/IndexedDB et sur téléphone réel restent à réaliser.
- La relance réseau de l’audit npm a également été refusée par la revue automatique pour quota. Le dernier résultat disponible, pour le lockfile inchangé, indique 28 paquets signalés dont 8 élevés, contre 34/13 initialement. Résidus documentés dans `docs/security/web-hosting.md`.
- Les messages réels de la section Erreurs déployée ne sont pas accessibles ici. Le bouton de résolution classe les incidents ; il ne prouve pas la correction de chaque cause.

Voir `docs/security/2026-09-10-deployment.md` pour l’ordre de déploiement et les contrôles requis avant mise en production.
