# Expo SDK policy

StockMaster is officially pinned to Expo SDK 54 until a dedicated, tested
migration is approved. Use only the exact SDK 54 documentation when changing
Expo APIs: https://docs.expo.dev/versions/v54.0.0/

Do not upgrade Expo, React, React Native, Node, or Expo-managed packages as part
of unrelated work. SDK 57 requires a separate migration project and Node 22.
